# Contributing

Contributions are always welcome, no matter how large or small!

We want this community to be friendly and respectful to each other. Please follow it in all your interactions with the project. Before contributing, please read the [code of conduct](./CODE_OF_CONDUCT.md).

## Prerequisites

- [Node.js](https://nodejs.org/) — see the [`.nvmrc`](./.nvmrc) for the exact version
- [Yarn](https://yarnpkg.com/) (v1 classic)
- [Xcode](https://developer.apple.com/xcode/) (for iOS)
- [Android Studio](https://developer.android.com/studio) (for Android)
- [CocoaPods](https://cocoapods.org/) (`gem install cocoapods`)

## Project Structure

```
├── src/                  # TypeScript source (JS API)

│       ├── WearablesModule.kt   # Native implementation
│       └── WearablesPackage.kt  # React package registration
├── ios/                  # iOS native module (Obj-C++)
│   ├── Wearables.h
│   └── Wearables.mm
├── lib/                  # Build output (generated by bob)
├── example/              # Example React Native app
└── Wearables.podspec     # CocoaPods spec for iOS
```

## Development Workflow

This project is a monorepo managed using [Yarn workspaces](https://yarnpkg.com/features/workspaces). Install all dependencies from the root:

```sh
yarn
```

> Since the project relies on Yarn workspaces, you cannot use `npm` for development.

### Running the Example App

The [example app](./example/) demonstrates all library features. It uses the local version of the library, so any changes you make to the source code will be reflected in the example app (JS changes are instant; native changes require a rebuild).

```sh
# Start Metro
yarn example start

# Run on Android
yarn example android

# Run on iOS (install pods first)
cd example/ios && pod install && cd ../..
yarn example ios
```

### Editing Native Code

- **iOS:** Open `example/ios/WearablesExample.xcworkspace` in Xcode. Library source is at `Pods > Development Pods > Wearables`.
- **Android:** Open `example/android` in Android Studio. Library source is under the `@rn-libs/react-native-wearables` module.

### Verifying New Architecture

The example app runs with the New Architecture (Fabric + TurboModules). Confirm by checking Metro logs:

```
Running "WearablesExample" with {"fabric":true,"initialProps":{"concurrentRoot":true},"rootTag":1}
```

## Code Quality

Before submitting a PR, make sure all checks pass:

```sh
# Type-check
yarn typecheck

# Lint (auto-fix with --fix)
yarn lint

# Unit tests
yarn test
```

## Commit Message Convention

We follow the [Conventional Commits](https://www.conventionalcommits.org/) specification:

| Prefix      | Purpose                                                     |
| ----------- | ----------------------------------------------------------- |
| `feat:`     | New features (e.g. add new API method)                      |
| `fix:`      | Bug fixes (e.g. fix Android isPaired returning wrong value) |
| `refactor:` | Code refactoring without behaviour change                   |
| `docs:`     | Documentation changes                                       |
| `test:`     | Adding or updating tests                                    |
| `chore:`    | Tooling, CI, dependency updates                             |

Our pre-commit hooks verify the format automatically.

## Sending a Pull Request

> **First time contributing?** Check out [How to Contribute to an Open Source Project on GitHub](https://app.egghead.io/playlists/how-to-contribute-to-an-open-source-project-on-github).

1. Fork the repository and create your branch from `main`.
2. Make your changes — prefer small, focused PRs.
3. Add tests if applicable.
4. Make sure `yarn lint`, `yarn typecheck`, and `yarn test` pass.
5. Update documentation if you changed the public API.
6. Open your PR and fill in the template.
7. For API or architecture changes, open an issue first to discuss the approach.

## Publishing to npm

We use [release-it](https://github.com/release-it/release-it) to publish new versions:

```sh
yarn release
```

This handles version bumping (semver), git tags, and npm publishing.

## Scripts Reference

| Script                 | Description                        |
| ---------------------- | ---------------------------------- |
| `yarn`                 | Install all workspace dependencies |
| `yarn typecheck`       | Type-check with TypeScript         |
| `yarn lint`            | Lint with ESLint                   |
| `yarn test`            | Run unit tests with Jest           |
| `yarn example start`   | Start Metro for the example app    |
| `yarn example android` | Run example on Android             |
| `yarn example ios`     | Run example on iOS                 |
| `yarn example web`     | Run example on Web                 |
| `yarn prepare`         | Build the library output           |
| `yarn clean`           | Remove build artifacts             |
| `yarn release`         | Publish a new version              |
